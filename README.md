## The entry

One emoji, and nothing else:

```
😄
```

A grinning face with smiling eyes: a big, genuine, open smile. A stranger
glancing at a phone screen reads it at once as warm, friendly and gently
cheerful, with no context, irony or intimacy needed. It is chosen rather
than the default smiley, and it is the kind of face most likely to make
someone smile back.

## How it works

`main.ts` writes the fixed emoji, and nothing else, to `/output/entry.txt`.
There is no randomness, no network access and no input: every run produces
the exact same bytes.

```sh
node main.ts
cat /output/entry.txt
```
